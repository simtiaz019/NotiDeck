# Security policy

NotiDeck 0.1.x has not had an independent security audit. Do not expose setup or the
application directly to the public internet. Read docs/security.md.

For vulnerabilities, use GitHub's private vulnerability reporting for this repository.
If it is unavailable, open a non-sensitive issue asking a maintainer for a private contact
channel; do not include vulnerability details in that issue. Do not publish exploits with
real keys, passwords, notification payloads, or personal data.

Reports should include affected version, reproduction steps using synthetic data,
expected impact and suggested mitigation. Release maintainers must configure a private
reporting channel and triage reports privately.
