# Security policy

0.1.0rc1 is a release candidate and has not had an independent security audit. Do not expose setup
or the application directly to the public internet. Read docs/security.md.

For vulnerabilities, use the repository hosting platform's private vulnerability
reporting facility once enabled. If unavailable, contact a maintainer privately before
sharing details. No repository owner or security email has been designated, so no
contact address is invented here. Do not publish exploits with real keys, passwords,
notification payloads, or personal data.

Reports should include affected version, reproduction steps using synthetic data,
expected impact and suggested mitigation. Release maintainers must configure a private
reporting channel before public release.
